# GLOSSARY.md — 中英詞彙對照表(控制檔)

**目的**:統一整份簡報的用語。製作投影片時**一律以這份表為準**——同一個概念整份用同一個詞、中英對照與縮寫全名都照表。ref2pptx 會把這裡的「英文全名」直接用在投影片角落的「縮寫 = 全名」註記。

**怎麼用**:
- 每列一個詞。填「中文(主要用詞)」「英文 / 全名」;若是縮寫,英文欄放「縮寫 = 全名」。
- 有慣用簡稱或不希望出現的說法,寫在「備註」提醒。
- 表沒收錄的詞,製作時自行決定,但同一份簡報要一致;新出現又會重複的關鍵詞,回填到這裡。
- 引用原文 / 參考資料章節照原文,不套用本表。
